# Security Policy

## Responsible Disclosure

If you discover a security vulnerability or potential data issue within this demonstration repository, please follow our responsible disclosure policy:

1. **Do NOT open a public GitHub issue** detailing the vulnerability.
2. Send an email with details of the vulnerability to the project maintainers.
3. Include relevant technical details, steps to reproduce, and potential impact.

## Public Demo Statement

This repository is a **public demonstration model** operating exclusively on synthetic mock datasets and local environment variables. It does not contain or connect to live production infrastructure, internal databases, or real government data.
